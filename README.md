# negentropy_cef_simulation
Computational simulation exploring negentropy as a measure of aliveness using causal entropic force agents.

# Exploring Negentropy as a Measure of Aliveness through Causal Entropic Force Simulations

This repository contains the simulation code and output data for a final-year Biomedical Engineering dissertation at the University of Reading.

# Project Overview
This project investigates whether negentropy can serve as a quantitative measure of aliveness in a stochastic, dissipative environment.

Three agent strategies were compared:
- Random agent (baseline exploration)
- Greedy agent (short-term reward maximisation)
- Causal Entropic Force (CEF)-inspired agent (future-state exploration)

# Repository Structure
- `code/` – Python implementation of the simulation (final version: Version 9)
- `outputs/` – Processed outputs and statistical results used in the dissertation

# Outputs Included
- `summary_main.csv` – overall performance metrics (survival, energy, negentropy)
- `pairwise_main.csv` – statistical comparisons between agent types
- `robustness.csv` – multi-seed robustness results
- `robustness_stats.csv` – aggregated robustness statistics

# Notes
The final model used for analysis is Version 9.
